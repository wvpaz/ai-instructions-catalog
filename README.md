# AI Instructions Catalog

Welcome to the **AI Instructions Catalog** repository. This project serves as a curated knowledge base of setup guides, technical skills, stack architecture templates, prompt templates, and best practices designed to streamline and accelerate **AI-guided and AI-supported software development**.

---

## 🎯 Purpose & Goal

As AI-assisted development tools (such as Antigravity, GitHub Copilot, Cursor, Claude, ChatGPT, etc.) become standard in modern engineering workflows, providing structured, deterministic, and high-quality context is essential.

This repository aims to:
- **Standardize Stack Setup**: Provide clear architectural templates and initial scaffolding guidelines for various technology stacks.
- **Provide AI Guidance & Skills**: Supply technical rules, coding standards, and step-by-step instructions that AI agents can consume to produce idiomatic code.
- **Store Prompt & Context Templates**: Catalog reusable prompts and system guidelines tailored for engineering tasks, code review, architectural planning, and debugging.
- **Ensure Consistency**: Maintain uniform conventions across frontend, backend, database layers, and testing suites.

## 🚀 How to Use

### 1. Direct Context for AI Assistants
When asking an AI agent to scaffold, configure, or develop a service, provide the relevant markdown file (e.g., `@template-node-nest.md` or `@template-react-typescript.md`) as reference context to ensure the generated code matches the required architecture and dependencies.

### 2. Manual Project Scaffolding
Use the setup instructions and directory structures provided in each template file to bootstrap new repositories or modules manually with verified configurations.
